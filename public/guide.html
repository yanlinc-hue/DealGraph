如何上传与解析

  1. 导入聊天：在工作台点“导入聊天”，选择合法取得的 聊天记录 JSON v1。不能直接上传微信备份目录、iPhone 备份、截图或语音。
  2. 缩小范围：选会话和日期，排除日常私聊、媒体及不相关消息；检查“实际待发送文本”。选择文件时只在本机读取，没有上传。
  3. 连接大模型：默认 OpenAI / GPT-4o，也可选择页面支持的其他模型。仅在密码框填自己的 API key，再点“临时配置密钥”。不要把 key 发到聊天、文档或 GitHub。
  4. 发现节点：核对预览，勾选本次上传同意，点“发送并发现节点”。这是第一次上传与计费。
  5. 确认名单：核对人物、机构和项目，合并确实相同的对象，区分同名，补充遗漏。删除节点不等于从聊天文本删除姓名。
  6. 生成商业关系：确认名单后，再单独同意第二次上传，点“发送并生成商业关系图”。结果支持 2D / 3D、关系筛选、搜索和客户卡查看。待确认不代表已核实。
  7. 记录并保存：记录客户需求、项目阶段和下一步，点“加密保存”，设至少 12 字符密码，并确认下载文件。下次用“打开文件”恢复。

资料只在当前页面。刷新或关闭会丢失未保存内容；没有自动云备份、微信自动同步、团队共享或手机待办推送。

如何部署

DealGraph 独立仓库包含完整前端、后端、测试和部署配置。使用已部署的站点无需安装；自行部署需有源码访问权与相应许可。

  1. 安装 Node.js 24，在仓库根目录运行 npm ci，然后 npm run dev，打开 http://127.0.0.1:5174。
  2. 上线前运行 npm test，登录自己的 Cloudflare 账号，把 wrangler.jsonc 的 APP_ORIGIN 改为自己的完整 HTTPS 站点来源。
  3. 运行 npm run deploy；前端静态资源和模型接口作为同一个 Worker 一起发布，不需要 GitHub Pages。
  4. 测试导入、连接、解析和加密恢复。不要配置共享模型 key，不要提交客户数据或部署凭据。
