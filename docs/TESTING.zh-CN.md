# 测试记录与边界

口径日期：2026-09-09。以下区分已记录的产品功能测试与新的独立部署验收，不把旧环境可用当成新域名已上线。

## 如何运行

在 Node.js 24 环境、仓库根目录执行：

```sh
npm ci
npm test
npm run build
npm run deploy:check
```

`npm test` 包含离线测试和图谱渲染检查，后者也可单独运行 `npm run test:graph`。离线测试使用虚构输入和模拟模型响应，不需要真实 API key，不产生模型费用。服务端渲染检查不等于浏览器交互测试。发布到独立域名后，还需验收 `APP_ORIGIN`、`ASSETS`、同源 API、静态资源、下载和模型接口版本匹配。

## 独立迁移版已完成

`npm test` 的 **156 项离线测试全部通过**，并通过图谱服务端渲染检查；`npm run lint`、`npm run build` 通过。测试覆盖密钥隔离、两阶段上传同意、旧客户端拒绝、取消与迟到结果、原始聊天、商业范围、工作台状态和加密恢复。

`npm run test:workerd` 使用固定 Wrangler 4.92.0 打包，在隔离运行时验证七种模型的模拟处理、节点发现和取消，**零外部调用**。部署边界验证：缺失／非法 `APP_ORIGIN` 返回 503，错误域名返回 403；可信来源必须为精确 HTTPS Origin，不带末尾斜杠。

另以真实构建产物绑定本地 ASSETS 检查首页、指南、样例和全部静态文件，20 项通过。当前固定版本的 Miniflare 静态资源运行时不实现视频 Range 分段响应，另 6 项分段／长度检查未满足；直接调用 ASSETS 结果相同。视频可下载并在本地开发服务播放，但尚未验证新公网托管的视频拖动与 HEAD 长度，不能把本地模拟的通过项当成完整生产验收。

独立版中文演示已在本地浏览器重新录制：103.6 秒、1440×900、H.264，字幕直接显示在画面中；全片解码及关键帧检查通过。演示使用虚构输入，候选名单按实测记录重建、关系解析回放已跑通结果，零付费调用、零外部请求、零页面错误。实际加密保存并恢复了 2 个资料集、2 条备注与 3 项任务，密钥占位符未写入保存文件。

此前 Chrome 桌面与手机尺寸的 28 项交互记录只作为功能参考，不代表新公网部署已通过；手机尺寸模拟也不等于 iPhone Safari 真机。视频压缩了人工核对过程，不能证明全自动建图或每次得到相同结果。本次发布没有为 DealGraph 绑定新的公网域名。

## 历史虚构数据的真实 GPT-4o 测试

以下是真实 API 对全虚构聊天的历史测试，不是本轮迁移新增调用，也不是模拟模型响应。评分对象是“模型＋产品校验”最终接纳图谱，不是原始模型草稿。金标准在调用前冻结，不发送模型、不按输出改分；原样本是修复回归集，新样本虽独立生成，但人工补了节点。

| 项目 | 原含噪样本 | 新样本 |
| --- | --- | --- |
| 原始消息 → 所选文本 | 73 → 70 | 24 → 22 |
| 跳过媒体／排除未来消息 | 2 / 1 | 1 / 1 |
| 最终关系记录 | 21 | 18 |
| 明确肯定关系：结构、状态命中 | 18/19（94.7%） | 15/15 |
| 明确肯定关系：再含角色、比例 | 17/19（89.5%） | 14/15（93.3%） |
| 全部结构 TP / FP / FN | 21 / 0 / 3 | 18 / 0 / 0 |
| 全部结构＋状态 TP / FP / FN | 21 / 0 / 3 | 17 / 1 / 1 |
| 再含已注册角色、比例 TP / FP / FN | 20 / 1 / 4 | 16 / 2 / 2 |

结构精确匹配有向两端、关系类型、项目和引荐人。精确率＝TP/(TP+FP)，召回率＝TP/(TP+FN)；错误字段在对应严格层级各造成一个 FP、FN。原样本完整结构精确率 100%、召回率 87.5%；新样本含状态、角色和比例的精确率与召回率均为 88.9%。这些数字不是总体准确率或商业事实真伪认证。

全部金标准为原样本 24 条、新样本 18 条，包括否定、待定、历史和更正记录。只有聊天来源时，肯定关系仍为待确认，不是已核实交易。

## 明确存在的缺口

- 原样本漏 100% 持股、传闻收购和晚来持股更正；顾问边存在，但漏“财务顾问”角色字段。
- 新样本的更正只标为“有分歧”，未严格归为“不采用”；旧 9% 仍在冲突记录中，不能当成当前确认持股。
- 新样本顾问角色为“财务顾问服务”，与冻结标准“财务顾问”语义接近但严格字符串不一致，不是凭空造关系。
- 新样本人工合并／项目名核对后只发现 15/17 个目标节点，人工补入衡浦银行、松汀资本才得到完整名单。不能称全自动发现 17/17。
- 两组样本没有观察到额外日常聊天业务边，但样本小，不能据此保证所有噪声都能排除。同名身份仍需人工确认。
- 最终图谱不暴露结构化 `validFrom` / `validTo`。历史日期在引用中存在不等于日期字段完整还原；额外要求预注册非空日期结构化留存时，新样本只有 15/18。

已记录测试经过本机 HTTP → Worker 逻辑 → 官方 OpenAI，并验证加密工作台往返；不是客户真实微信环境全自动测试。保存的结果没有完整原始模型 facts，无法把最终漏项全部归因于模型本体，也不能宣称零条事实被后处理隔离。

## 后续验收要求

发布记录应包含源码提交、Worker 版本、最终测试数、域名、测试时间和未测项目。新部署必须验证错误 Origin、未同意、无 key、过期客户端不会触发收费调用；验证静态资产与 API 同源，取消后不更新旧结果。

客户真实数据测试需单独授权、缩小范围、做隐私检查。新准确率测试继续使用预先冻结的样本，分别报告节点覆盖、人工补点、结构、状态和字段；不能通过丢弃错误项、只计返回数量或反复试到成功来宣布全通过。

公开仓库只保留源码、说明、全虚构演示与必要离线测试。不发布评测原始响应、客户材料、运行日志、密钥或凭据。
